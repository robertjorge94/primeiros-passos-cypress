# Minha automação de cypress

Esse projeto utiliza Cypress para automatizar o teste de uma feature de login e uma feature para preencher dados do usuário.
Cypress é baseado na linguagem de programação Javascript e é um framework de testes de ponta a ponta, que permite desenvolvedores a escrever testes e executar em um navegador.

## Instalação
```bash
npm install
```
>**NOTA**
>
> É necessário ter o **Node** instalado

## Como rodar

# Abrir Cypress com UI
```bash
npm cypress open
```
# Abrir Cypress no terminal
```bash
npm cypress run
```
